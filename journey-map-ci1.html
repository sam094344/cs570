Project 1 · Step 3 / Journey map · CI 1

An assignment is a chain of small actions.

The participant moves from a Canvas task into personal planning, then back to Canvas to verify and submit. The vulnerable point is the gap between work sessions, when dates or requirements may have changed.

Case focusWork already in progress

Canvas is the entry and submission point; the plan also lives in a calendar, task list, notes, and course materials.

Sequence described in CI 1 Reported breakdown / workaround Design opportunity

From finding the task to closing the loop

Five stages distilled from the submitted CI 1 report

01

Find the task

Canvas, then course page

Open Dashboard or To Do, then enter the relevant course and assignment page.

Laptop · Dashboard · To Do
02

Make the work legible

Inspect requirements

Check due date, instructions, submission method, rubric, and attachments.

Assignment page · rubric · files
03

Carry it into a plan

Personal planning

Record course, task, date, and link; set reminders, prioritize, and break the work into steps.

Calendar · task list · notes
04

Return with context

After a pause or change

Recheck Canvas, the syllabus, recent announcements, and rubric; update the plan and write the next concrete action.

Multiple sources must be reconciled manually
05

Submit, then confirm

Close the loop

Check content, file name, and format; submit in Canvas, confirm the correct upload, then mark the task complete.

Upload receipt ≠ personal task marked done
Where the journey can break
A

A pause hides the restart point

An interruption can make it difficult to remember where work stopped.

Workaround in report: record a specific next action, not just “continue.”
B

A changed requirement makes the plan stale

A date or submission change can leave a manually maintained calendar out of date.

Workaround in report: compare Canvas, syllabus, announcements, and rubric; update the plan.
Design opportunity · proposal

Make a safe return possible.

Keep the authoritative course source and the student's personal next step connected across sessions.

At the taskKeep due time, rubric, attachments, and submit method beside the link.
On returnShow the last concrete action and make changed source details easy to recheck.
At completionSeparate “file uploaded” from “task closed” and show both states.
